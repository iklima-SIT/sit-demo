Build a working demo web app for SIT.

SIT is an AI-powered local intelligence concierge for travelers.

The demo should look like a WhatsApp conversation.

Goal:
Show how SIT understands the traveler before recommending places.

Brand:
SIT
Tagline:
Don't Just SIT.
Positioning:
Local knowledge. Global scale.

Design:

* Dark premium interface
* WhatsApp-style chat screen
* Mobile-first
* Clean and modern
* Luxury travel + AI startup aesthetic

Demo Flow:

User opens the app.

SIT says:

"Hey, I’m SIT. Before I recommend anything, I need to understand what kind of Koh Phangan you’re looking for."

Then ask diagnostic questions one by one:

1. Why are you coming to Koh Phangan?
   Options:

* Wellness
* Music & parties
* Remote work
* Romance
* Community
* Nature
* I’m not sure yet

2. How long are you staying?
   Options:

* 3–5 days
* 1 week
* 2–4 weeks
* 1–3 months
* Long-term

3. Do you ride a scooter?
   Options:

* Yes
* No
* I’m learning
* I prefer not to

4. How social do you want to be?
   Options:

* Mostly alone
* Balanced
* Very social

5. What do you want to avoid?
   Options:

* Tourist traps
* Feeling lonely
* Wasting money
* Wrong area
* Unsafe wellness experiences
* Bad parties

After the user answers, generate a personalized SIT-style recommendation.

Use this logic:

If user does not ride scooter:
Recommend staying around Hinkong, Srithanu or Thong Sala coastal areas.
Warn that remote areas can make transport expensive and difficult.

If user chooses wellness:
Recommend asking their goal before choosing yoga or wellness.
Mention that not every wellness activity is equally reliable.
Suggest researching facilitators.

If user chooses music & parties:
Explain that Koh Phangan is not only Full Moon.
Recommend not planning the whole trip around Full Moon.
Mention sunset gatherings and music culture.

If user chooses romance:
Recommend Hinkong sunset experiences.
If low tide: sunset picnic.
If high tide: SUP at sunset followed by cocktails.

If user chooses remote work:
Explain that productivity may drop at first because there are many activities.
After 2–3 months people usually build routines.

If user chooses community:
Recommend recurring activities, coworking spaces, yoga classes, cafés, women’s circles, beach sports and sunset gatherings.

If user chooses nature:
Recommend jungle hike, swimmable beaches and not only Instagram beaches.

End with:

"Want me to build your 3-day / 7-day / 1-month SIT plan?"

Add buttons:

* 3-day plan
* 7-day plan
* 1-month stay

Important:
Do not connect to a real AI API yet.
Use rule-based logic for now.
The goal is to create an investor demo, not a production chatbot.

Add a final screen:

"Google knows places. SIT knows reality."

"Let's check it in SIT."
